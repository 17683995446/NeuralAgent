🔄 请求处理流程说明

1. 认证阶段

验证用户身份，检查 JWT token 有效性，应用速率限制策略

2. 解析阶段

解析请求参数，识别请求类型（Agent/Workflow/RAG），路由分发

3. 执行阶段

根据请求类型执行相应逻辑，包括 Agent 处理、工作流编排、RAG 查询

4. 响应阶段

处理结果格式化，更新记忆系统，返回响应给用户
